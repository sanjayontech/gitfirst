About gitfirst

Making your first open-source contribution easier than ever.

🎯

What is gitfirst?

A curated feed of good first issues — tasks labeled as beginner-friendly by maintainers of popular open-source repositories.

⚙️

How it works

A Python pipeline fetches open issues with beginner labels from a curated list of GitHub repos and generates the data shown here.
